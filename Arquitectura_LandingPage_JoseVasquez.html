1. Resumen Ejecutivo y Alcance

El proyecto landingpage-jav978 es una Single Page Application (SPA) moderna, ultra-rápida y de alto rendimiento diseñada para presentar el portafolio profesional de José Vásquez (Desarrollador Full Stack, Administrador de Infraestructura IT y Diseñador UI/UX).

3. Desglose de Capas del Sistema

Capa / Módulo Tecnología Principal Responsabilidad y Función
Capa de Presentación React 19 + TypeScript + Vite Renderizado desacoplado del frontend, manejo de estado reactivo (tema claro/oscuro, idioma ES/EN, modales de proyectos y CV).
Estilos y UI Engine Tailwind CSS v4 + Google Fonts Tipografía compuesta (Outfit + Plus Jakarta Sans), animaciones clave, medidores SVG circulares de habilidades y tarjetas Glassmorphic.
Servicio de Formulario Formspree API REST (JSON POST) Envío asíncrono y seguro de mensajes de clientes con validación y manejo transparente de errores.
Infraestructura y Build Vite Bundler + Docker / Vercel Empaquetado optimizado con minificación, generación de assets estáticos y despliegue continuo de alta disponibilidad.

4. Componentes Principales de la Interfaz

  • Navegación Flotante: Control de tema (Dark/Light), conmutador de idioma dinámico (ES/EN) y acceso rápido al Curriculum Vitae.
  • Sección Hero: Titular con degradado de marca, botones CTA triples, avatar orgánico con resplandor ambiental y badges flotantes de roles.
  • Medidores Circulares SVG: Visualizadores gráficos de porcentaje para competencias clave (React/Next.js, Vue.js, Tailwind CSS, Node.js, Docker, DevOps).
  • Portafolio Destacado: Tarjetas interactivas con capturas, etiquetas técnicas y enlaces en vivo (*Colegio Santa Luisa, Valet Parking, Sistema Veterinario, Electronic Shop*).
  • Formulario de Contacto: Integración directa con correo `jvasquez978@gmail.com`, teléfono `+58 426 521 7116` y botones de WhatsApp directo.

5. Atributos de Calidad

  • Rendimiento: Carga inicial ultra-rápida con bundles optimizados de Vite.
  • Responsividad: Adaptación total para pantallas desde dispositivos móviles (780px) hasta pantallas 4K.
  • Accesibilidad y Mantenibilidad: Estructura modular basada en componentes desacoplados de React y clases Tailwind estándar.
